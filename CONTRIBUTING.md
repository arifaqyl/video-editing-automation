# Contributing

## Before Opening a PR

- keep changes focused
- prefer small patches over broad rewrites
- document any new env var or local dependency in `README.md`
- avoid committing local media, logs, or generated subtitle/output files

## Local Checks

- verify the main script still runs
- verify `.env` stays untracked
- keep public-facing docs accurate if behavior changes

## PR Notes

Include:
- what changed
- why it changed
- how you verified it
